- **Why**: U26 (`docs/phase0/README.md`, the owner, 2026-10-04) makes a static claim citable:
  static findings are first-class (U16), but today only a run id counts as a citation, so goal2's

- **Owns**: `tools/check_citations.py`, `tests/tools/**`, `formats/README.md`,
  `formats/templates/finding.md` (one sentence on the static citation)
- **Scope**:
  - **Protects:** citation integrity in every game repository. None of these may get through:
    - a bullet or table row passing as cited by a `static:` token that names no tracked path in
      the repository;
    - a path that is absolute, contains a `.` or `..` segment, or resolves outside the repository
      root, including through a symlink;
    - a path that exists on disk but is not tracked by git;
    - a `:line` that is 0, past the file's last line, or given for a directory;
    - a malformed `static:` token anywhere in the file, accepted silently;
    - a crash or traceback on any input instead of a named error;
    - any weakening of the run-id checks, or of U25 and U27–U31.
  - **The token.**
    - A static citation is `static:` at the start of a line or after a character that is not a
      letter, digit or `_`.
    - Its argument is the run of non-space characters after the colon. Trailing characters from
      `` ` . , ; : ) ] } ' " * `` are removed.
    - The argument must match `<path>[:<line>]` in full:
      - `<path>` is one or more segments of `[A-Za-z0-9_.-]`, separated by `/`, with an optional
        trailing `/`;
      - no segment is `.` or `..`, and there is no leading `/`;
      - `<line>` is a decimal without a leading zero.
    - Any other `static:` token is the named error `<file>:<line>: malformed static citation:
      <token>`.
    - Every `static:` token anywhere in the file is checked, as run ids are, not only those in
      protected sections.
  - **The check.**
    - The repository root is `--root DIR`, default the working directory, never relative to the
      script.
    - The path must be listed by `git -C <root> ls-files` (a directory: some tracked file under it).
    - Resolved, it must stay inside the root.
    - `:line` needs a file with at least that many lines.
    - Each failure is the named error `<file>:<line>: static citation <token>: <reason>`.
    - A root that is not a git repository, or a `git` that is missing, is one named error, exit 1.
  - **Counting as cited:** in `## Answer` and `## Inferences`, a list item or a table data row
    holding a static citation is cited, as one holding a run id is (U26). Malformed or failing
    tokens still fail the file.
  - **Docs:**
    - `formats/README.md` gains the citation form and its checks, beside the U25–U31 rules.
    - `formats/templates/finding.md` gains one sentence.
  - **Not in scope:**
    - short-form run ids (U26: never);
    - any change to `verify_evidence.py`, `validate_records.py`, `register_artifact.py`, a schema
      or an example;
    - editing any game repository (their migration is goal2-archaeology#36,
      isle-wars-archaeology#57 and toy-archaeology#16).

- **Hazards**:
  - **Checking existence with `Path.exists()` alone.** That passes untracked and escaping paths.
    Use `git ls-files`, then resolve and check containment.
  - **Matching `static:` only inside protected sections.** A malformed token elsewhere would go
    unseen; run ids are checked file-wide, and so are these.
  - **A greedy argument** that swallows trailing punctuation or backticks, so that a correct
    citation fails, or a lax one that accepts `static:x)y`.
  - **Leaving the clones in the worktree.** Remove the temporary folder.
