# T05 Formats corrections before formats-v1 (#14 items 1–8)

- **Kind**: correction (of T02, bug #14)
- **Issue**: #15 · **Branch**: `task/T05-formats-corrections` · **Merge after**: T04
- **Implementer**: opencode (the default, `deepseek-flash`) · **Claude fallback**: sonnet
- **Reviewer**: opencode (`sol`); never the implementer's family. **Guard task** (CLAUDE.md rule 20):
  the formats checker decides which run records and manifests are valid, so a defect here lets a
  corrupt record pass as evidence (record integrity).
- **Why**: A6 freezes the formats as `formats-v1`. The reviewer replay of 2026-10-03 found eight
  defects in them that are still on `main`. A frozen format must not carry known defects.
- **Evidence** (pasted from #14, each re-checked on `main` at 6d4c43b):
  1. **An aborted run with no observations cannot be recorded.** `run/1` requires
     `observations.minItems: 1` but allows `status: aborted: <reason>`, and the protocol says an
     aborted run is "recorded as aborted, never dropped".
  2. **The valid I0 example records a screenshot.** `examples/valid/run-1--pure-observation-aborted.json`
     lists `{"level": "I0"}` but has a `source: screen` observation, which
     `vocabulary/interventions.md` classes as I1. A passing example that teaches the wrong level.
  3. **The same example contradicts itself.** It lasts 4 s, while its abort reason says "within
     40 s". As run E002 it names E001's action script and the `release:E001` store.
  4. **`pattern` uses `re.search`, where `$` also matches before a trailing newline.** A sha256 of 64
     hex characters plus `"\n"` passes this checker but fails an ECMA-semantics 2020-12 validator.
     Use `re.fullmatch` or `\Z`.
  5. **Canonical path sorting is never exercised.** The valid artifact-set example has one file.
     Removing the sort from `canonical_set_hash` (`tests/formats/check_examples.py:96`) leaves the
     checker green.
  6. **The never-empty `interventions` rule is not exercised.** Deleting `minItems: 1` leaves the
     checker green, because no invalid example has `interventions: []`.
  7. **`formats/README.md:38` cites `354d8265…532f`.** The `532f` tail traces to nothing. The source
     (`docs/phase0/01-existing-systems.md:159`) writes `354d8265…`.
  8. **`tools/check_links.py` matches only inline links** (brackets, then the target in parentheses), not reference-style
     links (`[text][ref]` with a `[ref]: target` definition), while its docstring and CI step say every
     relative link resolves. It also checks an inline link written inside a code span, which is not a
     link: this task file had to avoid writing one.
- **Owns**: `formats/**`, `tests/formats/**`, `tools/check_links.py`
- **Scope**:
  - Items 1–8 above, each with the smallest change that fixes it. Item 8 includes skipping code
    spans, as fenced blocks are already skipped.
  - **Item 1, the decision**: a run whose `status` is `aborted: <reason>` may have zero
    observations. A `completed` run still needs at least one. Express it in the schema with keywords
    the checker implements (it has `anyOf`); if a keyword must be added to the checker, add it to
    `KEYWORDS` and implement it.
  - **Items 2 and 3**: correct the example so that every observation source it records is allowed
    at the intervention level it declares (by `vocabulary/interventions.md`), its duration agrees
    with its abort reason, and every reference in it is to its own experiment. Rename the file if
    its name stops describing it.
  - **New examples** go in `formats/examples/{valid,invalid}/`, named like the existing ones.
  - **Not in scope**: any new field, rule or schema version; `vocabulary/`, `method/`, `docs/`; the
    other items of #14 (the ADRs and the protocol, done in A6 or later).
- **Done when** (each runnable by a read-only reviewer, who stages instead of committing):
  1. `python3 tests/formats/check_examples.py` exits 0, and `python3 tools/check_links.py` exits 0.
  2. **Each fix is proven by a check that fails without it.** For each of items 1, 4, 5, 6 and 8,
     the PR body names the example or fixture that covers it and shows the checker's output twice:
     with the fix reverted (`git show main:<file> > <file>` for the fixed file, keeping the new
     examples), where it exits 1 naming that example or fixture; and with the fix restored

     `sorted(...)` on line 96; item 6 by deleting `minItems: 1` from `interventions` in
     `formats/run-1.schema.json`.
  3. Item 1: a valid example of an aborted run with `"observations": []` passes, and an invalid
     example of a `completed` run with `"observations": []` fails.
  4. Item 4: an invalid example whose sha256 is 64 hex characters followed by `\n` fails.
  5. Items 2 and 3: in the corrected example, every observation's `source` is allowed at its declared
     level per `vocabulary/interventions.md` (quote the line), the duration agrees with the reason,

  6. Item 7: `grep -rn "532f" formats` prints nothing.

- **Hazards**:
  - **Weakening a check to make an example pass.** Every change makes the checker stricter or more
    exercised, never looser, except item 1's aborted-run allowance, which is the decision above.
  - **A new example that passes for the wrong reason.** Each invalid example breaks exactly one rule,
    and the checker's message names that rule.
  - **Editing `vocabulary/` to fit the example.** The example changes; the vocabulary does not.
  - **Paths outside the worktree.** Scratch work goes in `scratch/` inside the worktree. Never
    `/tmp`, never `cd`, never `..`.
