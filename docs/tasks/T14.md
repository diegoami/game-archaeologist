  - `docs/adr/005-multi-machine-claims.md`: claim = atomic `claim/T<nn>` ref at a claim commit

    `claim T<nn> machine=<id> at=<iso> issue=<n> nonce=<hex>`) + `machine:<id>` label + claim

  - `tools/harness/claim.mjs` at b05e0d8 (harness_imperial, T17): implemented, with stdout as one

    error, 2 usage.
- **Owns**: `method/drills/01-race-test/**`
- **Scope**:
  - **Protects:** the drill's honesty. The two attempts must be genuinely concurrent (a recorded
    start barrier), on a scratch task nobody else claims, with the raw gh api claim log committed
    unedited next to the report. None of these may happen: a simulated second machine; a claim log
    edited by hand; a `claim.mjs` change smuggled in (a defect found in it goes to harness_imperial).
  - On a scratch task in this repository, run `claim.mjs claim` from two machines at a recorded
    barrier, 10 races; record each race's gh api outcomes (201 win vs 422/409 loss) and both
    machines' ids. The replay parses the `claim-api` lines on stdout (see Evidence).
  - Write `method/drills/01-race-test/report.md` and `replay.mjs`; the replay re-parses the raw log
    and asserts exactly one 201 per race.
  - Retire the provisional status in `docs/adr/005-multi-machine-claims.md`, citing the report
    (rule 17: phase 0 records change only by a recorded decision — this drill is its basis).
  - **Not in scope:** the next two A7 milestones, any change to `claim.mjs`.
- **Done when**:
  1. `git ls-files method/drills/01-race-test/` lists at least `report.md`, `replay.mjs` and the raw
     claim log.
  2. `node method/drills/01-race-test/replay.mjs` exits 0 and prints
     `races: 10 / single-winner: 10 / multi-winner: 0 / no-winner: 0`.
  3. `grep -c 'machine:' method/drills/01-race-test/report.md` prints at least 2 (both machines).
  4. `grep -c 'still provisional' docs/adr/005-multi-machine-claims.md` prints 0, and
     `grep -c '01-race-test' docs/adr/005-multi-machine-claims.md` prints at least 1.
  5. CI is green.
- **Hazards**:
  - Sequential attempts dressed up as a race: the report must name the barrier mechanism and the
    timestamp window each pair landed in.
  - Claiming a real task: the scratch task is labelled `drill` and closed when the drill ends.
  - The replay must read the raw stdout (one `claim-api` line per ref write), not a hand-edited
    summary. A refactor of `claim.mjs`'s stdout that changes the line format is its own task.
